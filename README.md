# Netflix Subscriber Churn Prediction

A machine learning project that predicts whether a Netflix subscriber is likely to **churn (cancel their subscription)** using **Logistic Regression**.

## 📌 Project Overview

This project builds a simple, transparent AI/ML classification model to predict subscriber churn. Since Netflix's real subscriber data is private, the notebook uses a **realistic synthetic dataset** containing 3,000 subscriber records.

The project is designed to be easy to understand and demonstrate in a classroom or portfolio setting, while still following a practical machine learning workflow.

## 🎯 Objectives

* Predict subscriber churn using Logistic Regression
* Generate and analyze synthetic subscriber data
* Preprocess categorical and numerical features
* Train and test a classification model
* Evaluate model performance
* Understand which features influence churn predictions
* Perform individual subscriber churn predictions

## 📊 Dataset

The synthetic dataset contains **3,000 subscriber records** with the following features:

| -------------------- | --------------------------------------- |
| `tenure_months`      | Length of the subscriber's subscription |
